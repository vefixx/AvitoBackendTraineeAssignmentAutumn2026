# API-сценарии заведения

- Перевод статуса заведения в открыто/закрыто
- Просмотр своего меню
- Добавление нового блюда в меню
- Изменение информации о блюде в меню
- Изменение статуса наличия блюда
- Удаление блюда из меню
- Просмотр заказов
- Принятие нового заказа
- Отклонение заказа
- Перевод статус заказа в следующий
