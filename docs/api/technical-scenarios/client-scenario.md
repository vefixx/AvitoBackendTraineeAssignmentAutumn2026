# API-сценарии клиента

- Просмотр списка заведений
- Просмотр меню заведения
- Подробная информация о блюде
- Добавление в корзину
- Просмотр текущей корзины
- Удаление блюда из корзины
- Изменение кванта у блюда в корзине
- Оформление заказа (отправка заказа в заведение)
- Просмотр текущего статуса заказа
- Отмена заказа

## Сценарии

### 1. Просмотр списка заведений

| -                         | -                                                                                                                                                                        |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                  | Получить список заведений с возможностью фильтрации и пагинации                                                                                                          |
| **Эндпоинты**             | `GET /restaurants?category={category}&page={page}&pageSize={page_size}`                                                                                                  |
| **Что получает сервер**   | QUERY: `category` (string), `page` (int), `page_size` (int) (0 < x <100)                                                                                                 |
| **Что делает сервер**     | Производит валидацию данных. Если валидация прошла успешно, то выполняет запрос к БД на получение `page_size` записей, пропустив предыдущие `page_size*(page-1)` записей |
| **Что делает БД**         | В таблице заведений сортирует по `id`, пропускает `page_size*(page-1)` и извлекает `page_size` записей.                                                                  |
| **Что возвращает БД**     | Список заведений, находящиеся на указанной странице.                                                                                                                     |
| **Что возвращает сервер** | Результат запрос к БД: список из сущностей заведений                                                                                                                     |
| **Постусловия**           | -                                                                                                                                                                        |

| Проблема                                                      | Решение                                    |
|---------------------------------------------------------------|--------------------------------------------|
| Значение `page` находится вне диапазона                       | Вернуть `200 OK` с пустым список заведений |
| Значение `page_size` находится вне диапазона (>= 100 или < 0) | Вернуть `400 Bad Request`                  |
| Невалидный `category`                                         | Вернуть `400 Bad Request`                  |

### 2. Просмотр меню заведения

| -                         | -                                                                                                                                                                                                   |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                  | Получить актуальный список блюд у заведения, не включая те, которых нет в наличии, с возможностью пагинации                                                                                         |
| **Эндпоинты**             | `GET /restaurants/{restaurant_id}/menu?page={page}&pageSize={page_size}`                                                                                                                            |
| **Что получает сервер**   | QUERY: `restaurant_id` (long), `page` (int), `page_size` (int) (0 < x <100)                                                                                                                         |
| **Что делает сервер**     | Производит валидацию данных. Если валидация прошла успешно, то выполняет запрос к БД на получение `page_size` записей, пропустив предыдущие `page_size*(page-1)` записей                            |
| **Что делает БД**         | В таблице блюд получает все блюда, которые привязаны к заведению по `restaurant_id`. Фильтрует их по `dish_id` и `in_stock = true`, пропускает `page_size*(page-1)` и извлекает `page_size` записей |
| **Что возвращает БД**     | Список блюд заведения, находящиеся на указанной странице.                                                                                                                                           |
| **Что возвращает сервер** | Результат запроса к БД: список сущностей блюд у заведения.                                                                                                                                          |
| **Постусловия**           | -                                                                                                                                                                                                   |

| Проблема                                                      | Решение                                    |
|---------------------------------------------------------------|--------------------------------------------|
| Значение `page` находится вне диапазона                       | Вернуть `200 OK` с пустым список заведений |
| Значение `page_size` находится вне диапазона (>= 100 или < 0) | Вернуть `400 Bad Request`                  |
| Невалидный `restaurant_id`                                    | Вернуть `400 Bad Request`                  |                                                                                                                                                                    |
| Заведение с указанным `restaurant_id` не существует           | Вернуть `404 Not Found`                    |   

### 3. Подробная информация о блюде

| -                         | -                                                                                                                              |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                  | Получить подробную информацию о конкретном блюде заведения                                                                     |
| **Эндпоинты**             | `GET /restaurants/{restaurant_id}/menu/{dish_id}`                                                                              |
| **Что получает сервер**   | QUERY `restaurant_id` (long), `dish_id` (long)                                                                                 |
| **Что делает сервер**     | Производит валидацию данных. Если валидация прошла успешно, то выполняет запрос к БД на получении подробной информации о блюде |
| **Что делает БД**         | В таблице блюд получает блюдо заведения, фильтруя про `restaurant_id` и `dish_id`.                                             |
| **Что возвращает БД**     | Подробную информацию о блюде.                                                                                                  |
| **Что возвращает сервер** | Результат запроса к БД: подробная информация о блюде заведения.                                                                |
| **Постусловия**           | -                                                                                                                              |

| Проблема                                                              | Решение                                               |
|-----------------------------------------------------------------------|-------------------------------------------------------|
| Невалидный `restaurant_id`                                            | Вернуть `400 Bad Request`                             |
| Заведение с указанным `restaurant_id` не существует                   | Вернуть `400 Bad Request`                             |
| Блюдо с указанным `dish_id` не существует                             | Вернуть `404 Not Found`                               |
| Блюдо с указанным `dish_id` не привязан к заведению с `restaurant_id` | Вернуть `404 Not Found` (у заведения нет этого блюда) |

### 4. Добавление в корзину

| -                         | -                                                                                                                                                                                                                                                                 |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                  | Добавить блюдо в корзину пользователя.                                                                                                                                                                                                                            |
| **Эндпоинты**             | `POST /cart/items`                                                                                                                                                                                                                                                |
| **Что получает сервер**   | BODY: `restaurant_id` (long), `dish_id` (long), `count` (int), `client_id` (long)                                                                                                                                                                                 |
| **Что делает сервер**     | Производит валидацию данных. Если валидация прошла успешно, то выполняет запрос к БД на получение блюда, валидирует, и добавляет в корзину                                                                                                                        |
| **Что делает БД**         | Из таблицы блюд получает блюдо заведения, фильтруя по `restaurant_id` и `dish_id`; Добавляет в корзину пользователя новое блюдо (или увеличивает количество, если оно уже есть).                                                                                  |
| **Что возвращает БД**     | Информацию о позиции в корзине: ID блюда, ID заведения, новое количество                                                                                                                                                                                          |
| **Что возвращает сервер** | Результат запроса к БД: ID блюда, ID заведения, новое количество                                                                                                                                                                                                  |
| **Постусловия**           | - Блюдо добавлено в корзину пользователя <br/>- Если блюдо уже присутствовало в корзине, то его количество увеличилось на `count` <br/>- В корзине находятся блюда одного заведения <br/>- Количество одного блюда не превышает находится в диапазоне 0 < x < 100 |

| Проблема                                                                               | Решение                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------|
| Невалидный `restaurant_id`                                                             | Вернуть `400 Bad Request`                                             |
| Заведение с указанным `restaurant_id` не существует                                    | Вернуть `400 Bad Request`                                             |
| Блюдо с указанным `dish_id` не существует                                              | Вернуть `404 Not Found`                                               |
| Блюдо с указанным `dish_id` не привязан к заведению с `restaurant_id`                  | Вернуть `404 Not Found` (у заведения нет этого блюда)                 |
| Блюдо пытаются добавить в корзину, но его количество равно 99                          | Вернуть `409 Conflict`                                                |
| Значение `count` не находится в диапазоне 0 < x < 100,                                 | Вернуть `400 Bad Request`                                             |
| Клиент с `client_id` не существует                                                     | Вернуть `404 Not Found` (пользователь не найден)                      |
| В корзине находятся блюда другого ресторана                                            | Вернуть `409 Conflict` (в корзине должны быть блюда одного заведения) |
| Блюдо пытаются добавить в корзину, но его новое значение количества выйдет за диапазон | Вернуть `409 Conflict`                                                |

### 5. Просмотр текущей корзины

| -                         | -                                                                                                                                                              |
|---------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                  | Получить список блюд, находящиеся в корзине                                                                                                                    |
| **Эндпоинты**             | `GET /cart/items?client_id={client_id}`                                                                                                                        |
| **Что получает сервер**   | QUERY: `client_id` (long)                                                                                                                                      |
| **Что делает сервер**     | Валидирует входные данные. Проверяет существование клиента. Если проверки пройдены, запрашивает все позиции корзины.                                           |
| **Что делает БД**         | Получает все позиции корзины пользователя по `client_id`. Получает актуальную информацию о блюдах: ID блюда, ID ресторана, название, цена, количество, наличие |
| **Что возвращает БД**     | Список позиций корзины: ID блюда, ID заведения, название, цена, количества, наличие.                                                                           |
| **Что возвращает сервер** | Список позиций корзины, общую стоимость и информацию о заведении.                                                                                              |
| **Постусловия**           | -                                                                                                                                                              |

| Проблема                       | Решение                           |
|--------------------------------|-----------------------------------|
| Некорректный `client_id`       | `400 Bad Request`                 |
| Клиент с указанным `client_id` | `404 Not Found`                   |
| Корзина пустая                 | `200 OK` с пустым списком позиций |
