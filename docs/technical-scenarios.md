## Бизнес-правила

1. Заказ может находиться в статусах `new`, `accepted`, `cancelled`, `in_process`, `ready`
2. Переход между статусами заказа должен идти строго по правилу `new` -> `accepted` -> `in_process` -> `ready` в случае,
   если заказ принят. Выполнить отмену заказа можно в любом из этих состояний, кроме состояния `ready`
3. В корзине клиента могут находиться блюда только из одного и того же заведения.
4. Для блюда в корзине можно установить максимальное количество - 99.
5. Клиент может отменить заказ только, если заказ находится в состояниях `new`, `accepted` или `in_process`.
6. Если заказ находится в статусе new более 10 минут, то он автоматически должен отменяться.

## Сущности

- **Клиент** состоит из: ID клиента, Логин, Номер телефона
- **Заведение** состоит из: ID заведения, Название, Описание, Категория кухни, Статус (закрыто=false/открыто=true)
- **Блюдо** состоит из: ID блюда, ID заведения, Название, Описание, Состав, Цена, Статус наличия (true/false)
- **Позиция заказа** состоит из: ID позиции, ID заказа, ID блюда, Количество, Название на момент добавления, Цена на
  момент добавления
- **Заказ** состоит из: ID заказа, ID заведения, ID клиента, Адрес доставки, Статус, Дата создания
- **Позиция в корзине** состоит из: ID заведения, ID блюда, ID клиента, Количество, Название на момент добавления, Цена
  на момент добавления

## Сценарии

### Сценарии клиента

#### 1. Просмотр списка заведений

| -                               | -                                                                                                                                                                      |
|---------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                        | Получить список заведений с возможностью фильтрации и пагинации                                                                                                        |
| **Постусловия**                 | -                                                                                                                                                                      |
| **Какие эндпоинты затрагивает** | `GET /restaurants?category=&page=&pageSize=`                                                                                                                           |
| **Что получает сервер**         | `category` (string), `page` (int), `pageSize` (int) (0 < x <100)                                                                                                       |
| **Что делает сервер**           | Производит валидацию данных. Если валидация прошла успешно, то выполняет запрос к БД на получение `pageSize` записей, пропустив предыдущие `pageSize*(page-1)` записей |
| **Что делает БД**               | В таблице заведений сортирует по `id`, пропускает `pageSize*(page-1)` и извлекает `pageSize` записей.                                                                  |
| **Что возвращает БД**           | Список заведений, находящиеся на указанной странице.                                                                                                                   |
| **Что возвращает сервер**       | Результат запрос к БД: список из сущностей заведений                                                                                                                   |

| Проблема                                                     | Решение                                    |
|--------------------------------------------------------------|--------------------------------------------|
| Значение `page` находится вне диапазона                      | Вернуть `200 OK` с пустым список заведений |
| Значение `pageSize` находится вне диапазона (>= 100 или < 0) | Вернуть `400 Bad Request`                  |
| Невалидный `category`                                        | Вернуть `400 Bad Request`                  |

#### 2. Просмотр меню заведения

| -                               | -                                                                                                                                                                                                 |
|---------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Цель**                        | Получить актуальный список блюд у заведения, не включая те, которых нет в наличии, с возможностью пагинации                                                                                       |
| **Постусловия**                 | -                                                                                                                                                                                                 |
| **Какие эндпоинты затрагивает** | `GET /restaurants/{restaurant_id}/menu?page=&pageSize=`                                                                                                                                           |
| **Что получает сервер**         | `page` (int), `pageSize` (int) (0 < x <100)                                                                                                                                                       |
| **Что делает сервер**           | Производит валидацию данных. Если валидация прошла успешно, то выполняет запрос к БД на получение `pageSize` записей, пропустив предыдущие `pageSize*(page-1)` записей                            |
| **Что делает БД**               | В таблице блюд получает все блюда, которые привязаны к заведению по `restaurant_id`. Фильтрует их по `dish_id` и `in_stock = true`, пропускает `pageSize*(page-1)` и извлекает `pageSize` записей |
| **Что возвращает БД**           | Список блюд заведения, находящиеся на указанной странице.                                                                                                                                         |
| **Что возвращает сервер**       | Результат запрос к БД: список сущностей блюд у заведения.                                                                                                                                         |

| Проблема                                                     | Решение                                    |
|--------------------------------------------------------------|--------------------------------------------|
| Значение `page` находится вне диапазона                      | Вернуть `200 OK` с пустым список заведений |
| Значение `pageSize` находится вне диапазона (>= 100 или < 0) | Вернуть `400 Bad Request`                  |
| Невалидный `restaurant_id`                                   | Вернуть `400 Bad Request`                  |                                                                                                                                                                    |
| Заведение с указанным `restaurant_id` не существует          | Вернуть `404 Not Found`                    |
