# Бизнес-правила
1. Заказ может находиться в статусах `new`, `accepted`, `cancelled`, `in_process`, `ready`
2. Переход между статусами заказа должен идти строго по правилу `new` -> `accepted` -> `in_process` -> `ready` в случае,
   если заказ принят. Выполнить отмену заказа можно в любом из этих состояний, кроме состояния `ready`
3. В корзине клиента могут находиться блюда только из одного и того же заведения.
4. Для блюда в корзине можно установить максимальное количество - 99.
5. Клиент может отменить заказ только, если заказ находится в состояниях `new`, `accepted` или `in_process`.
6. Если заказ находится в статусе new более 10 минут, то он автоматически должен отменяться.
